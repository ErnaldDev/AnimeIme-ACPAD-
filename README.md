# 🗂️ Items Application Manager

---

## 🛠️ Tech Stack
- **Frontend / UI Framework**: Ionic 8 + Angular 17 (TypeScript), Angular Router  
- **Mobile Runtime**: Capacitor 6 (Android & iOS), with native plugins:  
  App · Camera · Geolocation · Haptics · Keyboard · Status Bar  
- **Backend / BaaS**: Firebase (Firestore + Authentication) via `@angular/fire` & Firebase SDK  
- **Tooling**: Angular CLI 17, Ionic CLI, Karma/Jasmine tests, ESLint  

---

## 🚀 How to Run

### Prerequisites
- Node.js (v18+)
- npm
- Angular CLI: `npm install -g @angular/cli`
- Ionic CLI: `npm install -g @ionic/cli`

### Run in browser (development)
```bash
# Install dependencies
npm install

# Start local server
ionic serve
